# Getting Started with AI Test Generator

This guide will help you get started with AI Test Generator.

## Installation

### Prerequisites

- Python 3.8 or higher
- pip package manager
- Git (for cloning the repository)

### Install from Source

```bash
# Clone the repository
git clone https://github.com/yourusername/ai-test-generator.git
cd ai-test-generator

# Create and activate virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install the package
pip install -e .
```

### Verify Installation

```bash
ai-test-gen --version
```

## Quick Start

### 1. Generate Tests for a Single File

Create a simple Python file `calculator.py`:

```python
def add(a: int, b: int) -> int:
    """Add two numbers."""
    return a + b

def divide(a: int, b: int) -> float:
    """Divide a by b."""
    if b == 0:
        raise ValueError("Cannot divide by zero")
    return a / b
```

Generate tests:

```bash
ai-test-gen analyze calculator.py
```

This will create `tests/test_calculator.py` with comprehensive test cases.

### 2. View Generated Tests

```python
"""
Generated test cases for calculator.py
Auto-generated by AI Test Generator
"""

import pytest
from calculator import *


# Tests for add

def test_add_happy_path_0():
    """Test add with valid inputs"""
    result = add(a=1, b=1)
    assert result is not None
    assert isinstance(result, int)


def test_add_boundary_value_1():
    """Test add with zero for a"""
    result = add(a=0, b=1)
    assert result is not None


# Tests for divide

def test_divide_exception_test_0():
    """Test divide raises ValueError"""
    with pytest.raises(ValueError):
        divide(a=1, b=0)
```

### 3. Run the Generated Tests

```bash
pytest tests/test_calculator.py -v
```

## Common Use Cases

### Analyze Entire Project

```bash
ai-test-gen analyze-project ./src --output ./tests
```

This will:
- Find all Python files in `./src`
- Generate corresponding test files in `./tests`
- Include edge cases and boundary tests

### Generate Tests from User Stories

Create a file `story.txt`:

```
As a user,
I want to login with my email and password,
so that I can access my account securely
```

Generate tests:

```bash
ai-test-gen user-story story.txt --output tests/test_login.py
```

### Custom Configuration

Create `.ai-test-gen.yml`:

```yaml
test_framework: pytest
include_edge_cases: true
max_tests_per_function: 15
output_directory: tests/
```

Then run:

```bash
ai-test-gen analyze myfile.py --config .ai-test-gen.yml
```

## Python API Usage

You can also use AI Test Generator programmatically:

```python
from ai_test_generator import TestGenerator

# Initialize
generator = TestGenerator()

# Analyze a file
test_cases = generator.analyze_file('path/to/file.py')

# Generate test file
output_path = generator.generate_test_file(
    'path/to/file.py',
    output_path='tests/test_generated.py',
    include_edge_cases=True
)

print(f"Tests generated: {output_path}")
```

## Troubleshooting

### ImportError: No module named 'tensorflow'

TensorFlow is optional. If you don't need ML features:

```bash
pip install -r requirements.txt --no-deps
pip install numpy PyYAML pytest
```

### Tests not generating

Check that:
1. Your Python files have proper type hints
2. Functions have docstrings
3. Output directory exists and is writable
